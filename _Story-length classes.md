# Story Length Classes

| Class | Word count |
|-------|-----------|
| Flash fiction | Up to 999 |
| Short story | 1,000 to 7,499 |
| Novelette | 7,500 to 17,499 |
| Novella | 17,500 to 39,999 |
| Novel | 40,000 and up |

The short-story-through-novel boundaries are the official SFWA Nebula Award categories. Flash fiction (under ~1,000) is a common informal addition, not an SFWA category.

The Stats block in each story's `_Index.md` computes the **current** class automatically from the live word count, so a work reclassifies itself as it grows. This is mechanical and fluid: it reflects what the draft is right now, not what it was planned to be.

A story's intended `form:` (in its `_Index.md` frontmatter and `CLAUDE.md`) is a separate thing: it records the author's target, which can differ from the current count. A piece begun as a short story may end as a novel; the target and the current class need not match.
